# StackChan 触摸反馈的台词库。
#
# 改这个文件 → 跑 make_touch_voices.py → WAV 落到
#   SD-staging/app/AiStackChanEx/voice/<分类>/
# 每个分类下设备会随机抽一句播。
#
# ★ 2026-07-28: 当前设备采用 0.92× 保音调后处理。重新合成任何一句后，先用
#   装好 TTS 依赖的 Python venv 运行 tools-voice/stretch_touch_voices.py 生成 0.92× 版本，
#   听过并认可后再写 SD 卡；不要把 make_touch_voices.py 的原速输出直接覆盖到卡上。
#
# 写台词的几条实测约束：
#   - 短。合成 wall ≈ 2.5s + 2.7 × 音频秒，但这些是**离线**预合成的，
#     慢一点无所谓；短的真正理由是"被摸一下"的反应本来就该是一两个词。
#   - 中文 TTS server（:8125）的单块上限是 18 字，超了会被切段、段间补停顿。
#   - 空行和 # 开头的行会被忽略。
#   - 断句旋钮(2026-07-26 实测): **半角空格 ≈ 90ms 轻节奏停顿**,
#     **逗号 ≈ 300ms+ 重断句**(还常常让模型在别处多切一刀)。
#     想要「喘口气」用空格, 想要「两句话」才用逗号。
#   - 一个分类放 3~12 句都行（设备侧上限 12 句/目录）。

[pat]
# 拍一下头
诶，干嘛呀。
有什么指示？
在呢在呢。
怎么啦？
好好好，我醒着。

[pet]
# 顺着撸
嘿嘿，再摸一下。
再摸头就大了。
摸摸小机器人头，万事不用愁。
OWNER 是揉面大师来的。
嘿嘿。

[pet_back]
# 逆着撸
诶，怎么摸反了。
开始 不要生气挑战。
毛都乱了。
摸完要把我发型变回去。

[shake]
# 被摇晃
晕了晕了。
别再晃啦。
我在干活呢，你这不是瞎闹吗？
我要散架了。
